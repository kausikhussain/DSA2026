## 🛠️ How to Compile & Run

All solutions are written in clean, self-contained **Java** with built-in test cases in the `main` method.

### Prerequisites
- **JDK 17 or higher** installed.

### Execution
To run any solution from the command line:

```bash
# Example 1: Run 3Sum
javac Practice/ThreeSum.java
java Practice.ThreeSum

# Example 2: Run Rotting Oranges
javac Practice/RottingOranges.java
java Practice.RottingOranges

# Example 3: Run Minimum Platforms (Infosys)
javac Infosys/MinimumPlatforms.java
java Infosys.MinimumPlatforms
```

## 💡 Key Design Decisions & Code Standards
1. **Self-Contained Execution**: Every file contains a working `main()` method with diverse unit test cases and expected outputs.
2. **Optimal Complexity First**: Problems prioritize time-optimal and space-optimal approaches (e.g., $O(1)$ auxiliary space wherever possible).
3. **Documented Rationale**: Each implementation includes clear problem statements, step-by-step logic, and time/space complexity annotations.
